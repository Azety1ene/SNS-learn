# ロードマップ

SNS を完成させるまでの全手順（約 65 ステップ）と進捗です。1 ステップ ＝ 1 つの PR が基本です。

- 【あなた】が付いた作業は、オーナーがスマホで行います（手順はその都度案内します）
- 終わったステップにはチェックを付けます

## 進め方

1. オーナーがチャットで「次のステップを進めて」と指示する
2. Claude が作業ブランチで実装し、自動テストと型チェックを通す
3. Claude が PR を作る（何を・なぜ・学びポイント・スマホでの確認手順）
4. GitHub Actions がテストし、Vercel がプレビュー環境を作る
5. オーナーがスマホでプレビューを触り、コードを読み、分からない行にコメントで質問する
6. 納得したらオーナーがマージし、本番に自動で反映される

### 各ステップの完了条件

- 自動テストがあり、CI が通っている（コードを含むステップ）
- プレビュー環境でスマホから動作を確認できた（画面があるステップ）
- 学習ノートと ROADMAP が更新されている
- オーナーがマージした
