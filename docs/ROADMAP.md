# ロードマップ

SNS を完成させるまでの手順と進捗です。PR は「まとまった機能（マイルストーン）」ごとに 1 本ずつ出します（[ADR-0006](adr/0006-milestone-workflow.md)）。

- 【あなた】が付いた作業は、オーナーがスマホで行います（手順はその都度案内します）
- 終わった項目にはチェックを付けます

## 進め方

1. オーナーがチャットで「次へ進んで」と指示する
2. Claude がマイルストーンの機能をまとめて実装し、自動テストを通してから PR を作る
3. オーナーは PR に書いた「まず読むファイル」と学習ノートを読み、分からないところを質問する
4. 納得したらオーナーがマージし、本番に自動で反映される

## 学ぶテーマ（絞り込み）

- **Next.js の「サーバーとブラウザの分担」**（Server Components／Client Components／Server Actions）
- **DB の設計とクエリ**（テーブル・制約・インデックス・トランザクション・マイグレーション）
- それ以外（テスト、CI、設定ファイル、ログインのライブラリの設定など）は品質のために入れますが、読まなくて構いません
