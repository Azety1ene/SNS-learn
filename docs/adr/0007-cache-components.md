# ADR-0007: Next.js の Cache Components を使い、画面部品は Tailwind CSS で作る

- 状態: 承認
- 日付: 2026-10-23

## 背景

- Next.js 16 では、新しく作ったプロジェクトで Cache Components（と Partial Prefetching）が最初から有効になっている。次のメジャーバージョンでは常に有効になる予定
- Cache Components では、Cookie や DB のように「リクエストのたびに変わるもの」を読む部品を `<Suspense>` で囲まないと、ビルドがエラーになる
- ADR-0002 では、画面部品に shadcn/ui を使う予定だった

## 決定

- Cache Components を有効のまま使う
- ページの外枠（ヘッダーや見出し）はすぐに表示し、ログイン状態や DB を読む部分は `<Suspense>` で囲んで、読み込めしだい流し込む（ストリーミング）
- 当面は `"use cache"` によるキャッシュは使わない。SNS のデータは見る人によって変わり（いいね済みかどうかなど）、常に新しい方がよいため。性能が必要になったら検討する
- 画面部品は Tailwind CSS だけで作り、アイコンには lucide-react を使う。shadcn/ui は、ダイアログなど複雑な部品が必要になったときに導入する

## 理由

- これから Next.js を学ぶなら、今後の標準になる書き方を身につけた方がよい
- `<Suspense>` の位置を意識することで、「どこがサーバーの処理待ちなのか」が自然と分かる
- M1 の画面は単純なので、部品ライブラリなしでも十分に作れる。ファイルが少ない方が読みやすい

## 影響

良い点

- 画面の外枠が一瞬で表示される
- 今後の Next.js の標準に沿っている

注意点

- Cookie や DB を読む部品をうっかり `<Suspense>` の外に置くと、ビルドがエラーになる（エラーメッセージが直し方を教えてくれる）
- `usePathname()` のように URL を読むフックも、`<Suspense>` の fallback では使えない（`src/components/bottom-nav.tsx` を参照）
