# ADR-0002: 技術スタック

- 状態: 承認
- 日付: 2026-10-23

## 背景

- オーナーは Next.js を勉強中で、Next.js を使いたい
- 無料枠だけで運用する。カードの登録もしない
- 利用者は少数の想定
- オーナーはスマホからしか操作しないので、変更をスマホで確認できる仕組みが必要
- モックは使わず、本番で運用できる品質にする

## 決定

| 役割 | 採用するもの |
| --- | --- |
| フレームワーク | Next.js（App Router）＋ React ＋ TypeScript |
| ホスティング | Vercel（Hobby プラン） |
| データベース | Neon（PostgreSQL） |
| DB の操作 | Drizzle ORM（マイグレーションは drizzle-kit） |
| 画像の保存 | Vercel Blob |
| 認証 | Better Auth（ADR-0003） |
| 見た目 | Tailwind CSS ＋ shadcn/ui |
| 入力チェック | Zod |
| テスト | Vitest、Playwright（ADR-0005） |
| CI | GitHub Actions |
| パッケージ管理 | pnpm |

## 理由

- **Vercel**: Next.js の開発元で、Next.js の機能をすべてそのまま使える。PR ごとにプレビュー URL を作って PR にコメントしてくれるので、スマホでの確認と相性がよい。無料プランはカード不要で、上限を超えても課金されず止まるだけ
- **Neon**: 業界で広く使われている PostgreSQL を、無料・カード不要で使える。しばらく使われないと休止するが、次のアクセスで自動的に再開する（Supabase の無料枠のように手動で復旧する必要はない）。Vercel と連携すると、プレビューごとに DB のコピー（ブランチ）を自動で作れる
- **Drizzle ORM**: SQL に近い書き方なので、ORM を使いながら SQL の理解も深まる。テーブルの定義から TypeScript の型が自動で付く
- **Vercel Blob**: Vercel と統合されていて、カードの登録なしで使える
- **Tailwind CSS ＋ shadcn/ui**: shadcn/ui は部品のコードをリポジトリにコピーして使う方式なので、部品の中身まで読める
- **Zod**: 入力チェックのルールを、TypeScript の型と一緒に定義できる

## 影響

良い点

- すべて無料・カード不要で、上限を超えても請求が来ない
- Next.js の学習と、実務でよく使われる構成の学習を兼ねられる

注意点

- Vercel の無料プランは非商用の利用に限られる
- Vercel の関数は WebSocket のサーバーになれない。リアルタイム更新は定期的な再取得から始める
- 画像は保存 1GB・アップロード等が月 2,000 回まで。画像機能は上限のガードとセットで作る（要件定義の「6. 制約（無料枠）」）
- Neon は休止明けの最初のアクセスが遅くなる
- Neon の DB ブランチは 10 個まで。マージ済みの作業ブランチは削除し、プレビュー用の DB ブランチをためない

## 検討した他の案

- **Cloudflare Workers ＋ Hono ＋ D1 ＋ R2**: 無料枠は手厚いが、Next.js を学びたいという希望に合わない。R2 はカードの登録が必要
- **Supabase**: 認証・画像保存・リアルタイムをまとめて任せられるが、その分、自分で作って学ぶ部分が減る。無料枠は 7 日間使われないと休止し、手動での復旧が必要
- **Prisma**: Next.js でよく使われる ORM。Drizzle の方が SQL に近く学習の目的に合うため、採用しなかった
